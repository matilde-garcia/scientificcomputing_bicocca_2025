Q3. This package also offers the option for other users to contribute to the code. Upon a certain pull request, the merge with the main
branch will be approved/denied depending on if the new code passes/fails the tests (available under the /tests directory)
which preform both unit and regression tests. For the regression tests, the benchmark status of the code is under the 
folder "benchmark".
